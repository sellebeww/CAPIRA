# 5-minute demo script (honest)

Preparation: Android phone + Chrome, app already opened once online ("Ready offline"), phone stand, glass slide / clear plastic, one healthy volunteer.

| Minute | Action | What to say |
|---|---|---|
| 0:00 | Show **Airplane Mode** on, open CAPIRA | "Everything runs on the phone. No internet, no cloud." |
| 0:30 | **New assessment** → enter sample vitals (RR 24, systolic 98, GCS 15, age 45) | "qSOFA is computed deterministically per Sepsis-3 — not AI. A blank is not counted as zero." |
| 1:15 | **Scan CRT** on the volunteer (protocol A: clear slide). Point out the light/stability guidance, then follow the PRESS/RELEASE cues | "The app standardizes the press duration at 10 seconds, like the ANDROMEDA-SHOCK protocol." |
| 2:00 | Live result: **normal CRT** (most likely) — open the explanation panel: curve, 2/3 s lines, quality table | "Our volunteer is healthy, so the result is normal — which is what it should be. Every number comes with its evidence." |
| 2:45 | Show a rejection: repeat with a moving finger / covered ROI → **Low Data Quality** + reasons | "When the data is bad, CAPIRA refuses to give a number. Better no number than a wrong one." |
| 3:30 | **Simulation Mode** → "Febrile adult, prolonged CRT" (purple SIMULATION banner) | "To show a prolonged case we use a synthetic signal — clearly labelled, not patient data." |
| 4:15 | **Referral draft** → Share / SMS | "A draft from a template, offline. The recommendation is non-directive: consider evaluation/referral per local protocol." |
| 4:45 | Closing | "Status: calculation accuracy is proven on synthetic signals; real-camera validation is the next step, with the protocol & pass criteria already written." |

**Don't:** present simulation results as live · say "detects sepsis/shock" · quote any number that is not ✅ in CLAIMS.md.
